# Calculadora em React

Projeto desenvolvido em React utilizando Vite para criar uma calculadora simples.

## Funcionalidades

- Entrada do primeiro número
- Entrada do segundo número
- Seleção de operação
- Adição
- Subtração
- Multiplicação
- Divisão
- Botão Calcular
- Botão Limpar
- Exibição do resultado

## Conceitos aplicados

- Componentes React
- useState
- Eventos `onChange` e `onClick`
- Formulários
- Estrutura condicional com `if`
- Select e options
- Funções
- CSS para estilização

## Tecnologias

- React
- JavaScript
- HTML
- CSS
- Vite

## Como executar

Instale as dependências:
npm create vite@latest .
